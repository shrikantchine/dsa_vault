## 📚 Topic Quick Reference

### Data Structures - Key Points to Remember

#### Arrays
- **Time Complexity**: Access O(1), Search O(n), Insert/Delete O(n)
- **Key Techniques**: Two pointers, sliding window, prefix sums
- **Common Problems**: Subarray sum, max/min elements, rotation

#### Linked Lists  
- **Time Complexity**: Access O(n), Insert/Delete O(1) at known position
- **Key Concepts**: Dummy nodes, fast/slow pointers, cycle detection
- **Common Problems**: Reverse, merge, cycle detection, intersection

#### Stacks & Queues
- **Stack**: LIFO, O(1) push/pop
- **Queue**: FIFO, O(1) enqueue/dequeue  
- **Applications**: Expression evaluation, BFS/DFS, monotonic stack

#### Trees
- **Time Complexity**: Search/Insert/Delete O(log n) for balanced trees
- **Traversals**: Inorder, preorder, postorder, level-order
- **Common Problems**: Height, diameter, LCA, path sum

#### Graphs
- **Representation**: Adjacency list/matrix
- **Algorithms**: DFS, BFS, Dijkstra, Kruskal, Prim
- **Key Concepts**: Connected components, cycles, topological sort

### Algorithms - Essential Formulas

#### Sorting
- **Merge Sort**: O(n log n), stable, O(n) space
- **Quick Sort**: O(n log n) avg, O(n²) worst, in-place
- **Counting Sort**: O(n+k) when range is small

#### Dynamic Programming
- **Approach**: Optimal substructure + overlapping subproblems
- **Patterns**: 1D/2D DP, knapsack, LIS, edit distance
- **Time**: Often O(n²) or O(n×m)

#### Greedy Algorithms
- **Key**: Local optimal choice leads to global optimum
- **Examples**: Activity selection, Huffman coding, MST
- **Proof**: Exchange argument or greedy stays ahead

### Mathematical Concepts

#### Time Complexity Quick Reference
- **O(1)**: Hash table access, array indexing
- **O(log n)**: Binary search, balanced tree operations
- **O(n)**: Linear scan, simple loops
- **O(n log n)**: Merge sort, heap sort
- **O(n²)**: Nested loops, bubble sort
- **O(2ⁿ)**: Recursive fibonacci, subset generation

#### Common Formulas
- **Sum 1 to n**: n(n+1)/2
- **Sum of squares**: n(n+1)(2n+1)/6
- **Geometric series**: a(rⁿ-1)/(r-1)
- **Combinations**: C(n,r) = n!/(r!(n-r)!)
